# Nahw Docs (النحو العربي)

Full in-depth classical Arabic syntax and grammar (*Nahw*) documentation built with [VitePress](https://vitepress.dev/).

## Topics Covered

- **[Getting Started (`/guide/getting-started`)](docs/guide/getting-started.md)** — Definition of *Al-Kalam* (utterance, compound, complete, conventional) from *Al-Muqaddimah Al-Ajurrumiyyah*.
- **[Al-Kalimah (`/guide/kalimah`)](docs/guide/kalimah.md)** — Diagnostic signs (*'alamat*) of *Al-Ism* (noun), *Al-Fi'l* (verb), and *Al-Harf* (particle).
- **[Al-I'rab & Al-Bina' (`/guide/irab`)](docs/guide/irab.md)** — The four grammatical states (*Raf'*, *Nasb*, *Khafd/Jarr*, *Jazm*) and primary/secondary markers across all noun and verb classes.
- **[Al-Jumlah (`/guide/jumlah`)](docs/guide/jumlah.md)** — Nominal (*Al-Jumlah Al-Ismiyyah*) and verbal (*Al-Jumlah Al-Fi'liyyah*) sentence structures.
